# 입력 데이터와 변수 설명

원자료와 개별 거래행은 제공하지 않습니다. 합성 데이터를 원 분석의 근거로 사용하지 않았습니다. 정확한 원 열 이름과 범주는 [input-schema.json](input-schema.json)에 있습니다.

| 입력 | 형식 | 필수 내용 |
|---|---|---|
| 법인 거래 | CSV · CP949 | `기준년월`과 원 45개 열. 한 행은 법인 관련 월별 관측 |
| 금리 | CSV · UTF-8 | `기준년월`, `평균대출금리(%)`, `평균예금금리(%)`, `예대마진(%)` |

금리 키는 월별로 유일하고 거래 데이터의 모든 월에 대응해야 합니다. 금액 변수는 백만원 단위, 건수·좌수는 원 범주 문자열입니다. 고유 법인 식별자는 없습니다. 추가 식별자나 연락처를 코드에 포함시키지 않습니다.

## 사용하는 파생변수

| 파생변수 | 구성 | 의미·주의 |
|---|---|---|
| 총예금잔액 | 요구불·거치식·적립식 예금 잔액 합 | 은행 내 예금 잔액 |
| 총대출잔액 | 운전자금·시설자금 대출 잔액 합 | 은행 내 대출 잔액 |
| 총예금좌수 | 세 예금 상품의 좌수 대표값 합 | 정확한 계좌 수가 아닌 근사치 |
| 총디지털거래액 | 인터넷·스마트·폰뱅킹 거래금액 합 | 채널 거래 활동 |
| 총오프라인거래액 | 창구·ATM 거래금액 합 | 오프라인 채널 거래 |
| 총카드소비 | 신용·체크카드 사용금액 합 | 카드 결제 활동 |
| 총외환실적 | 수출·수입 실적 금액 합 | 원자료의 외환 금액. 기업 전체 무역액으로 일반화하지 않음 |
| 예대마진 | 대출 잔액×금리−예금 잔액×금리 | %에 0.01 적용. 원가·위험 차감 전 추정치 |
| 총자산 | 예금+대출+수익증권+신탁 잔액 | 원코드 변수명이며 기업 재무제표 총자산이 아님 |

퇴직연금이 신탁에 포함된다는 원 주석은 확인된 데이터 정의로 보지 않습니다. 최종 핵심 모델은 해당 포함 관계를 예측 근거로 주장하지 않습니다.

## 대표값 매핑

| 구간 | 거래건수 대표값 | 좌수·개수 대표값 |
|---|---:|---:|
| 0 | 0 | 0 |
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 2 초과–5 이하 | 3.5 | 4 |
| 5 초과–10 이하 | 7.5 | 8 |
| 10 초과–20 이하 | 15 | 15.5 |
| 20 초과–30 이하 | 25 | 25.5 |
| 30 초과–40 이하 | 35 | 35.5 |
| 40 초과–50 이하 | 45 | 45.5 |
| 50 초과 | 55 | 55 |

상한 없는 구간에 55를 적용한 것은 원코드의 가정입니다. 새로운 데이터를 분석한다면 대표값 민감도를 검토해야 합니다. 정의되지 않은 범주나 수치형으로 이미 바뀐 입력은 자동 추측하지 않고 오류로 처리합니다.

## 단계별 입력 축

- **회귀 7개:** 여신한도금액, 총디지털거래액, 총오프라인거래액, 총카드소비, 총외환실적, 총예금좌수, 자동이체거래건수.
- **군집 4개:** 예대마진, 총예금좌수, 여신한도금액, 총디지털거래액의 변환·표준화 값.
- **지역 비교 9개:** 군집 4개 + 총오프라인거래액, 자동이체금액, 자동이체거래건수, 총외환실적, 총카드소비의 변환·표준화 값.

여신한도금액을 ‘남아 있는 대출 가능 금액’으로 단정하지 않습니다. 고객등급도 실제 산정식이 없으므로 외부 신용등급으로 해석하지 않습니다.
