# 지역별 캠페인 사후 분석 방법

2026-10-05 포트폴리오 보완 분석. 당시 실행 성과와 구분합니다.

1. `src/pipeline.py`의 원본 파생변수를 사용합니다. 기존 지역별 변환과 K-Means(42, n_init=auto)를 보존해 1차 기준집단 70,825행, 결합 131,541행, 최종 비교군 88,926행을 재현·검사합니다. 원 분석의 좌표 문제를 해결한 새 지역 순위가 아닙니다.
2. 대경·부산·경남·울산 79,059행에서 지역 프로파일을 계산합니다. 업종 30행 미만 항목은 출력하지 않아 업종 비중 합이 1보다 작을 수 있습니다.
3. 이용은 해당 항목 금액>0으로 정의합니다. 디지털 합, 카드 합, 수출입 합, 자동이체금액입니다. 상품 보유나 전환 여력과 구분합니다. 반올림·구간화 자료의 제약도 있습니다.
4. 같은 월의 예금+대출 합을 네 지역 전체 관측의 4분위로 나눕니다. 연도×업종 대분류×규모 구간마다 네 지역이 각각 30행 이상 있을 때 공통 층으로 채택합니다. 12개 층, 제조업·도매 및 소매업, 27,428행이 남았습니다. 모든 제조업·도소매업을 포함한 것은 아닙니다.
5. 층별 지역 평균에 전체 공통 층의 pooled 관측 비중을 동일하게 곱해 합산합니다. 대경 관측이 많아 기준 가중치에도 대경의 영향이 큽니다. 같은 공통 표본의 조정 전 평균도 JSON에 함께 저장했습니다. 전 지역 원 프로파일과 조정 결과의 차이에는 표본 제한 영향도 있으므로 순수 조정 효과로 표현하지 않습니다.
6. 연도별 원 비교군 이용 비율을 보조적으로 점검합니다. 같은 ID의 반복 여부를 알 수 없어 독립 관측 검정·고객 부트스트랩·p-value를 만들지 않습니다. 원 군집은 전체 기간으로 적합해 연도별 집계가 시간 외 검증을 뜻하지 않습니다.
7. 손익은 실제 고객 수와 관계없는 가상 정책입니다. 두 방식에 같은 1,200만 원을 배분하고, 같은 평가기간의 순증 거래당 기여이익을 100만 원으로 가정합니다. 규제·상품 가격·실제 은행 단가를 가정한 자료가 아닙니다. 유지 효과·위험·신용손실·실제 투입비를 측정한 성과로 사용하지 않습니다.

## 증거 추적

- 원 비교군 정의: `src/pipeline.py::historical_clusters`; 원 노트북 근거는 [기존 분석 근거](results-evidence.md).
- 지역별 원 프로파일: `assets/regional-campaign-results.json`의 `profiles`.
- 표준화 수치·포괄 범위: `adjustment.groups`, `common_industries`, `included_rows`, `candidate_rows`.
- 3개 연도별 보조 확인: `annual_profiles`.
- 동일 예산·손익분기 산식: `hypothetical_policy_scenarios`.
- 실행 코드: [regional_campaign_analysis.py](../scripts/regional_campaign_analysis.py).

지역별 제안은 위 집계에 근거한 해석이며, 실측 수요·최적 정책·효과 추정이 아닙니다. 정확한 입력 경로·해시는 공개 폴더 밖의 비공개 검토 기록에 보관합니다.
