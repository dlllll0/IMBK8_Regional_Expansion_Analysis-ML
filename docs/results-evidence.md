# 분석 근거와 재검토 사항

노트북 셀 번호는 **0부터 세는 JSON 셀 인덱스**입니다. 화면의 실행 번호 `In [ ]`와 다릅니다. PDF 페이지는 파일의 실제 페이지 순서입니다. 로컬 경로·원문·개별 거래행은 포함하지 않았습니다.

## 기준 자료와 선택 이유

| 코드 | 원자료 | 채택 범위 |
|---|---|---|
| A | `모델링 코드 정리본.ipynb` · 139셀 | 전처리, 기본 회귀, 1·2차 군집, 시도 코사인 유사도 |
| B | `3번_모델링 - 변수 선정 이유와 근거, automl, optuna - 피처임포턴스.ipynb` · 48셀 | 3개 모델 CV 비교와 튜닝 실행 이력, 원 변수 중요도 그림 |
| C | `예대마진_분석_파이프라인.ipynb` · 69셀 | 수익률 타깃의 초기 탐색. 최종 금액형 모델 결과에 혼합하지 않음 |
| D | `5조 발표자료.pdf` | 문제 정의, 전체 흐름, 원 사업 제안. 수치는 A/B와 대조 |
| E | 결과보고서 DOCX 및 같은 이름의 PDF | 기간·팀 구성·원 제안 확인. 파일명에 ‘통계학’이 있어도 내용은 ML 프로젝트 |
| F | 데이터 명세서 DOCX 2개·XLSX | 변수 설명 참고. 실제 헤더·코드와 다른 부분은 구분 |

A의 후반부에는 ‘안쓴 코드’라고 명시된 가중 군집, 유클리드·DTW 실험이 있습니다. 발표의 최종 코사인 경로와 일치하는 부분만 정리했습니다. B는 A와 일부 전처리가 다르지만 CV·튜닝 로그가 있는 별도 실험으로 보존했습니다. 파일명·수정일만으로 하나를 전체 최종본으로 단정하지 않았습니다.

## 충돌·오류와 반영 방식

| 발견 사항 | 공개본 처리 |
|---|---|
| D p.18 실루엣 0.52·K=4 최대 vs A의 K=2 최대 | A의 실제 저장 그래프 채택. K=4는 해석상 선택으로 설명 |
| D p.19도 상단 ‘K=4 최대’와 하단 ‘K=2 최고’가 충돌 | 최댓값 주장 제거. 엘보우 수치도 A 원본 그림 사용 |
| D의 0.7357을 튜닝 성능으로 읽기 쉬움 | A 기본 모델과 B 튜닝 0.7353을 별도 표시 |
| Optuna `n_trials=30` vs 중단 로그 | ‘30회 완료’ 제외. 17회 완료만 확인 |
| 초기 명세서 시작월 2022.03, 47열 표기 | 실제 CSV의 2022.01, 45열 사용 |
| 초기 수익률 타깃·0잔액 제외 설명 vs A 금액 타깃 | A의 활성 코드만 최종 흐름에 반영 |
| 회귀 7개·군집 4개·유사도 9개가 혼재 | 단계별 변수 수 구분. 발표의 ‘유사도 7개’ 미채택 |
| ‘3개 지표 모두 최고’와 실제 군집 중앙값 불일치 | 예금좌수·디지털 거래는 Cluster 0가 더 높음을 설명 |
| 지역별 로그 이동값·스케일러가 다름 | 기존 계산 재현용으로 보존. 공통 변환 기준 재검증 필요 |
| 시군구 동명 집계 | 확정 세부 순위는 공개 본문에서 제외. 복합 키 개선 과제로 명시 |
| 동일 변수로 집단 선택 후 유사도 측정 | 독립적인 예측 성능·진출 성공의 입증으로 표현하지 않음 |
| 개인 행을 포함한 `head()`·행 단위 CSV 저장 | 공개 노트북과 스크립트에서 제외 |

기존 모델의 정확한 라이브러리 버전과 실행 당시 모든 입력 상태는 확인되지 않았습니다. 현재 기본 RF의 재실행 결과는 저장값과 소폭 다릅니다. 환경 차이인지 저장 출력 상태 차이인지 원인을 확정하지 않았으며, 성능 개선이라고 주장하지 않습니다.

## PDF 설계 흐름 반영

발표자료 18쪽은 1차 대경 기준집단, 22쪽은 기준집단+타지역 재군집화, 23–24쪽은 최종 코사인 비교와 지역 결과의 근거입니다. 결과보고서 6–8쪽의 실험 이력은 유클리드·DTW 검토 후 최종 코사인 선택을 기록합니다. 실행 기준은 기존 노트북과 pipeline.py를 따릅니다.

22쪽은 식별자·내부 경로 없는 집계와 설계 그림을 시각 확인해 본문에 포함했습니다. 그림의 67.6% 분모 및 z-score 설명은 인접 캡션에서 바로잡았습니다. 18쪽의 실루엣 최고값 주장은 저장 노트북과 충돌해 이미지로 넣지 않고 검증된 군집 표로 대체했습니다. 23쪽의 7개 변수 설명은 최종 코드 9개와 달라 그대로 옮기지 않았습니다. 원 보고서의 통계적 증명·성장 잠재력 확정 표현도 관측 근거 이상의 주장으로 채택하지 않았습니다.
